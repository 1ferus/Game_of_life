# Игра «Жизнь» (клеточный автомат Джона Конвея)

Лабораторная работа №1 по курсу «Компьютерное моделирование».

## Описание

Реализация классического двумерного клеточного автомата «Игра Жизнь», разработанного Джоном Хортоном Конвеем в 1970 году. Несмотря на предельно простые локальные правила, модель демонстрирует богатое поведение: из случайного начального заполнения самопроизвольно возникают устойчивые, периодические и движущиеся структуры.

**Правила:**
- Живая клетка выживает, если у неё 2 или 3 живых соседа.
- Мёртвая клетка рождается, если у неё ровно 3 живых соседа.
- Во всех остальных случаях клетка умирает или остаётся мёртвой.

**Пространство:** квадратная решётка размером `m × m`.

**Состояния клетки:** `S = {0, 1}`, где 0 — клетка мертва, 1 — жива.

**Окрестность:** Мура (8 соседей).

**Границы:** периодические (тор). Клетки, вышедшие за границу поля, «появляются» с противоположной стороны.

**Обновление:** синхронное. Все клетки переходят в новое состояние одновременно, по состоянию поля на предыдущем такте.

**Начальное состояние:** случайное заполнение с заданной плотностью `p ∈ [0, 1]`.

### Правило перехода

Для клетки с координатами `(i, j)` и числом живых соседей `n`:

 Текущее состояние  Число живых соседей `n`  Новое состояние 

 жива (1)           2 или 3                  жива (1)        
 жива (1)           < 2 или > 3              мертва (0)      
 мертва (0)         3                        жива (1)        
 мертва (0)         любое другое             мертва (0)      


## Что исследуется

- влияние плотности начального заполнения `p` на эволюцию поля;
- устойчивость эталонных фигур (блок 2×2, мигалка, глайдер);
- переход системы между режимами: вымирание → стабилизация → хаос;
- плотность живых клеток `ρ(t)` во времени;
- время стабилизации и тип финального состояния.
